# Orbium v0.1.0 scope

This document is the scope boundary for the first release.

## Must ship

### Foundation

- Laravel 13 / PHP 8.4 application
- React 19 + TypeScript + Inertia
- Vite 8
- Tailwind CSS 4
- PostgreSQL
- authenticated user accounts
- user data isolation
- Docker self-host baseline
- automated formatting/lint/type/build/test commands

### Workspaces and hierarchy

- multiple workspaces per user
- create/rename/delete workspaces
- folder/document/database/board nodes
- parent-child relations
- containment validation
- move/reorder nodes
- no hierarchy cycles
- breadcrumbs
- trash/soft-delete behavior for user content
- workspace switcher

### Boards (requested 2026-10-18)

- fourth native Node type; a leaf at workspace root or inside a folder
- completed foundation: creation, explorer/navigation/search, favorites, page appearance, Trash, and native Board pages
- completed phases 1–3: hierarchy/navigation foundation, spatial persistence/canvas, independent typed native blocks, selection, movement/resize, clipboard, local undo/redo, debounced saves/conflict recovery and Library media
- phase 4 implementation (approved 2026-10-18): live resource cards, original Document editing/persistence, atomic sibling Document creation and Database/Board navigation cards
- drawing review extension (requested 2026-10-23): freehand pen/highlighter, point-by-point Path Pen, partial-stroke eraser with size controls, native Board persistence/selection/history, freehand smoothing and app-style drawing controls (template recognition removed after user review); see `24-boards.md`
- active phase 5 (authorized 2026-10-24): shared Mind Map block for native Boards and Markdown/legacy Documents, central topic and nested subtopics with basic editing/collapse/reparent controls; see `../phases/13-mindmap-block.md`
- remaining unspecified Mind Map features/later phases require explicit approval; the supplied source still cuts off mid-section
- native Board shapes (approved 2026-10-29): six editable vector shapes, fill/outline controls, rich labels and existing spatial interactions; see `../phases/15-board-shapes.md`; connected arrows and rotation require separate approval
- see `24-boards.md`; database Board views remain deferred and are distinct from native Boards

## Explicitly not in v0.1.0

See `docs/15-deferred-features.md` for detail.

The following are deferred:

- AI generation/editing/chat
- 2D global mention graph
- collaboration / multi-user shared workspaces
- comments
- real-time collaborative editing
- public sharing
- cloud hosted paid service
- offline-first/local-first sync
- mobile-first redesign
- database Board/List/Calendar/Timeline views
- Formula/Rollup/Person/Progress/Location properties
- required database properties
- database templates
- arbitrary relation properties
- 3D mention links
- global application CSS/themes and theme marketplace
- version history
- Redis
- Meilisearch/Elasticsearch
- WebSockets
- MinIO/S3 as required infrastructure
- physics-driven orbital layout
- plugin system

## Scope decision rule

If a requested implementation detail is not necessary to satisfy a must-ship item, prefer not to add it to v0.1.0.

A future-friendly schema is good. Shipping future functionality early is not.
