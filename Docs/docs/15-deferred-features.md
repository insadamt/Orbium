# Deferred features

These ideas are valid future directions but are **not** part of Orbium v0.1.0.

## Knowledge graph

- 2D global map of mentions
- mention-edge visualization
- graph analytics

The 3D Orbit remains hierarchy-only even after a future 2D map exists.

## AI

- chat with workspace
- generate documents
- rewrite blocks
- semantic Q&A
- AI database properties

Do not design v0.1.0 around a required AI provider.

## Collaboration

- shared workspaces
- roles/permissions beyond normal user ownership
- comments
- live cursors
- CRDT collaborative editing
- public links/sharing

## Database expansion

- Board
- List as a dedicated DB view
- Calendar
- Timeline
- Formula
- Rollup
- Person
- Progress
- Location
- required properties
- database templates

## Document expansion

- full version history
- global application CSS and theme marketplace (account-wide document block CSS was approved on 2026-10-05)
- plugin/extension ecosystem
- arbitrary embeds beyond initial safe block set

## Infrastructure

- Redis as a requirement
- Meilisearch
- Elasticsearch
- RabbitMQ
- WebSockets
- required S3/MinIO
- Kubernetes

Add infrastructure only when measured requirements justify it.

## Client/platform

- offline-first sync
- native mobile app
- mobile-first 3D redesign
- desktop native client

## Commercial/cloud

- hosted Orbium cloud
- billing/subscriptions
- paid tiers
- organization administration

The self-hosted v0.1.0 should not contain placeholder billing architecture.
