# Devicon language logos

Path data from the plain C#, Java, Objective-C and Visual Basic icons in
[Devicon](https://github.com/devicons/devicon), pinned to commit
`6a37858047b0e8d9c9c0e68f4a071fc410652e89`.

Source: `icons/{name}/{name}-plain.svg`, where name is `csharp`, `java`,
`objectivec`, or `visualbasic`. Paths retain their original 128×128 coordinate
system and render with the current theme foreground. The adjacent LICENSE
contains the upstream MIT license. Product names and marks belong to their owners.
